One sentence, written for a friend who has never coded, to talk them into
letting an AI agent build their first app idea on make.fun: no coding to
learn, just describe the idea, and a first version to try, free, while they
watch.

> You don't need to learn to code, just describe the app you keep imagining, and an AI agent on make.fun will build a first version you can try, free, while you watch.

## Run

```sh
python3 main.py
```

This writes the sentence to `output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
